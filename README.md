
# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Deployment

The best platform to deploy this Next.js project is **Firebase App Hosting**.

It's highly recommended for its seamless integration with Next.js and Genkit, offering a generous free tier and an easy-to-use deployment process.

Your project already contains an `apphosting.yaml` file, which is all you need to get started with deploying to Firebase.
